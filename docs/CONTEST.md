## Judging criteria (equally weighted, per the rules page)

1. **WebMCP Leverage** — how thoroughly and skillfully the project uses WebMCP.
2. **Execution** — a functional, complete product experience beyond a proof of concept.
3. **Potential Impact** — a credible case that it solves a real problem for a real audience.
4. **Creativity & Ambition** — a novel concept that differs from existing solutions.

## Required deliverables

- Working **live URL** judges can open in ChatGPT's in-app browser or Google Chrome with WebMCP enabled.
- **Text description** covering: why the use case fits WebMCP, how it improves the user experience, what humans and agents can do together, and how it was implemented.
- **Demo video** under 3 minutes, with audio, publicly posted to YouTube, showing the app and the WebMCP implementation.
- **Public code repository** (GitHub/GitLab/Bitbucket) with complete source, and an open-source **license file detectable and visible at the top of the repository page**.
- Functional WebMCP tools in the app.

## Eligibility rules that touch the repo

- Projects must be newly created in the submission period, **or** pre-existing and meaningfully extended with WebMCP after Aug 25. Pre-existing projects are judged only on window work and **must document prior vs. new work with evidence (dated commit history or equivalent)**.
- Third-party SDKs/APIs/data must be used under their terms.
- Entrants: age of majority; residents of countries with OpenAI API access; excluded jurisdictions listed on the page; no team-size limit stated.
- After the submission period ends, the Devpost submission cannot be changed (except to remove infringing/PII content).
